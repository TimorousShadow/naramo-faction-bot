# Contributing

1. Fork the repo and branch from `main`.
2. Run `npm ci` and `npm run typecheck` before you open a pull request.
3. Keep pull requests to one change and explain what it does in the description.

Code style:

- TypeScript, ES modules, strict mode.
- No code comments. The only exception is the first line of each file, which names the developer who wrote it.
- Messages users see go in Components V2 containers without an accent colour, with `nf_` icons from `src/ui.ts`.
